Luke is modular - start with the standard arm and expand with grippers, cameras, and software modules that plug into this web app.

Mechanics

Luke belongs to the SCARA family with a standard RPRR configuration. It can be configured as RPRRR by replacing the 1‑DOF hand with a 2‑DOF hand that adds twist, so the gripper can rotate about its gripping axis.

Base + arm

Rotary base and planar arm links for fast horizontal reach — classic SCARA strengths for pick-and-place.

Z column

Vertical displacement for height changes over the work surface.

Wrist & gripper

Optional twist module and interchangeable end effectors for gripping everyday objects.

Electronics & server

The on-board ESP32 server drives the motors, runs calibration, and exposes a WebSocket API. It is intentionally “dumb” and low power so it can stay on all the time — all the fancy interaction happens in this website.

  • Wi‑Fi setup via captive portal (Luke-<id> AP)
  • OTA firmware updates once on your network
  • USB‑C for programming (12 V supply still required for motors)
  • Open firmware via PlatformIO in the GitHub repo

Software modules (this app)

Connect

Joint sliders, quick moves, raw commands, and recorded-move playback.

Voice

Browser speech recognition that streams phrases to the robot.

Camera

ArUco / AprilTag-style marker detection for position-aware tasks from your phone camera.

AI / ML

Hook generative AI and custom models through the same web control path — no native app install required.

Programming interfaces

Beyond this UI you can drive Luke from Python, C#, JavaScript, C++, and other languages. Start from the examples in Get Started and the project wiki.
