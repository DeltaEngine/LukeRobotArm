Guides

Everything you need to unbox, assemble, connect, and program Luke. You do not need to install anything for normal use — this website is the controller.

Getting started

  1. Power & clear the area. On first run, calibration moves every joint through its range. Keep the workspace clear. On each power cycle the arm lowers fully to re-zero — nothing should be under it.
  2. Join the robot Wi‑Fi. Connect to Luke-<id>. Open http://192.168.4.1 if the portal does not appear, and enter your local Wi‑Fi credentials.
  3. Return to your Wi‑Fi and open this site. Use Connect with the robot’s IP so your phone or PC can control the arm.
  4. Pick a control mode: Controller, Voice, Camera, gamepad, or an external script / AI agent.

Camera & markers

Use the Camera page to detect ArUco markers on or around the arm for relative positioning. Print a marker from an ArUco generator or use the built-in test marker page.

Firmware / server (advanced)

  1. Clone DeltaEngine/LukeRobotArm and open the Server folder with PlatformIO in VS Code.
  2. End users do not need this — only flash if you want to change on-device behaviour.
  3. Wi‑Fi: wifiManager.autoConnect uses saved credentials or opens the Luke-<id> AP for setup.
  4. After the robot is on your network, prefer OTA uploads with --upload-port <device-ip>. USB‑C still works for programming, but the arm needs its 12 V supply for motors.

Programming examples

Drive Luke from Python, C++, JavaScript, C#, and more. Start from the wiki examples and the WebSocket protocol used by this site (JSON commands such as get_status, set_joints, move, voice, play).
